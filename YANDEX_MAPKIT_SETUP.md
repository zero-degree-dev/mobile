# Настройка Яндекс MapKit API ключа

## Проблема
В логах видна ошибка:
```
yandex.maps: Unexpected server response: Forbidden. Body :Invalid api key
```

Это означает, что используемый API ключ неверный или не подходит для Mobile SDK.

## Решение

### Шаг 1: Получите правильный API ключ

1. Перейдите на https://developer.tech.yandex.ru/
2. Войдите в аккаунт Яндекс (или создайте новый)
3. Создайте новый проект или выберите существующий
4. В разделе **"Карты"** выберите **"Mobile SDK"** (НЕ JavaScript API!)
5. Скопируйте ключ для **Android**
6. Вставьте его в `MainActivity.kt` вместо `"YOUR_MOBILE_SDK_API_KEY"`

### Шаг 2: Обновите код

В файле `app/src/main/java/com/example/zero_degree/MainActivity.kt`:

```kotlin
MapKitFactory.setApiKey("ВАШ_КЛЮЧ_MOBILE_SDK_ЗДЕСЬ")
```

### Важно!

- ❌ **НЕ используйте** ключ от JavaScript API
- ✅ **Используйте** ключ от Mobile SDK
- Ключ должен быть для **Android**, а не для iOS
- Ключ должен быть активен в вашем проекте на developer.tech.yandex.ru

### Проверка

После установки правильного ключа:
1. Пересоберите приложение
2. Запустите и откройте карту
3. Проверьте логи - ошибка `Invalid api key` должна исчезнуть
4. Карта должна отображаться с точками баров

## Альтернатива

Если у вас нет доступа к Яндекс Developer Console, можно временно использовать тестовый ключ или отключить карту до получения рабочего ключа.
